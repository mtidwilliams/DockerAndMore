🔷 Azure DevOps

Azure DevOps is a suite of services for planning, developing, and delivering software — from backlog to production.

Core services

Boards

Track work with backlogs, sprints, and Kanban boards.

Repos

Git repositories with pull requests and branch policies.

Pipelines

CI/CD to build, test, and deploy across any platform.

Test Plans

Manual and exploratory testing tools.

Artifacts

Host and share NuGet, npm, and Maven packages.

Sample YAML pipeline

A minimal pipeline that builds a Docker image and pushes it to a registry:

trigger:
  - main

pool:
  vmImage: 'ubuntu-latest'

steps:
  - task: Docker@2
    inputs:
      containerRegistry: 'myRegistryConnection'
      repository: 'myapp'
      command: 'buildAndPush'
      Dockerfile: '**/Dockerfile'
      tags: '$(Build.BuildId)'
Tip: Pair Azure DevOps Pipelines with Docker to build container images automatically on every commit.
