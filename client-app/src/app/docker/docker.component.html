🐳 Docker

Docker packages an application and its dependencies into a portable container that runs the same way on any machine.

Key concepts

Docker-image

A read-only template with your app and its dependencies. Built from a Dockerfile.

Container

A running instance of an image — isolated, lightweight, and disposable.

Registry

A store for images, such as Docker Hub or Azure Container Registry.

Common commands

CommandDescription
docker build -t myapp .Build an image from the current directory.
docker run -p 8080:80 myappRun a container and map host port 8080 to container port 80.
docker imagesList local images.
docker psList running containers.
docker stop <id>Stop a running container.
docker push myappPush an image to a registry.

Sample Dockerfile

FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
EXPOSE 3000
CMD ["npm", "start"]

How to create a Docker image

  1. Add a Dockerfile to the root of your project describing how to build and run the app (see the sample above).
  2. Create a .dockerignore file to exclude files like node_modules and build output from the image.
  3. Build the image with docker build -t myapp:latest . — the -t flag tags it and the . sets the build context.
  4. Verify it exists by running docker images and looking for myapp in the list.
  5. Run a container from the image with docker run -p 3000:3000 myapp:latest to test it locally.
  6. Push it to a registry with docker push myapp:latest so it can be pulled and deployed elsewhere.
